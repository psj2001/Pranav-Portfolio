## Where to edit

Change public facts in [src/data/siteContent.ts](src/data/siteContent.ts). Employment lives in the `experiences` array (`start` / `end` are inclusive calendar months; leave `end` unset when it is not confirmed). Training lives in the `training` array and is excluded from the employment total. Set a project’s `status` to `'public'` only after the contribution, stack, and links are filled in. Use `engagement` only when employment, freelance, or personal is confirmed, and `experienceId` only when the project belongs to a role. Page titles and descriptions live in [src/data/pageMeta.ts](src/data/pageMeta.ts). Official titles in a future CV should match this file.
